# 내 몸 보고서 | My Body Report

나를 읽는 100개의 질문 · 100 Questions to Read Your Body

**breathe&books · 고성 Goseong, Korea**

## 기능 | Features
- 100문항 자가 진단 (한국어 / English)
- 레이더 차트 시각화
- AI 내 몸 보고서
- 맞춤 수련 세션 (知·體·技·記)
